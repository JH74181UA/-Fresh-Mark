## 📱 Project Overview
A complete, functional Grocery Shopping Mobile Application built using **React Native**, **Expo**, **JavaScript**, and **React Navigation**.

### Key Features
- **User Roles:** Customer, Store Admin, and Super Admin with role-based access.
- **Three-Tier Navigation:** Stack Navigation, Bottom Tab Navigation, and Drawer Navigation.
- **Cart Management:** Live quantity +/- steppers, item removal, dynamic subtotal, discount, delivery fee, and total calculations.
- **Favorites / Wishlist:** Add and remove favorite items with 1-tap transfer to cart.
- **Admin & Super Admin Controls:** Inventory stock toggles, profile editing with photo selection, and master password controls.
- **Form Validation:** Validated forms for Sign In, Sign Up, Customer Profile, and Super Admin Profile.

## 🚀 Running the Project

```bash
# 1. Install dependencies
npm install

# 2. Start the Expo development server
npx expo start
```

Scan the QR code displayed in the terminal using the **Expo Go** app on your physical mobile phone.
